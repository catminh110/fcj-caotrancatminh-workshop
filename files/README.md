# Static Attachments Directory (`static/files/`)

Thư mục này dùng để lưu trữ các file đính kèm (tài liệu, template IaC, script) phục vụ tải xuống trực tiếp trong workshop và proposal.

## Cấu trúc thư mục

- `2-Proposal/` — Tài liệu đính kèm của Proposal (ví dụ: file PDF ước tính chi phí AWS Pricing Calculator, tài liệu thiết kế...).
- `5-Workshop/cloudformation/` — CloudFormation templates (`.yaml`, `.yml`, `.json`).
- `5-Workshop/terraform/` — Terraform configurations (`.tf`, `.tfvars`, `.zip`).
- `5-Workshop/docker/` — `Dockerfile`, `docker-compose.yml` và cấu hình container.
- `5-Workshop/scripts/` — Shell scripts, Python/Node.js scripts hoặc file cấu hình hỗ trợ triển khai.
